ABOUT THIS PROJECT

Made for students, by students.

CampusNotes is a simple college project demonstrating a clean, responsive study-material portal. It can be hosted on a Windows EC2 instance using IIS. The PDF files are served alongside the website; Amazon S3 can be added as an optional extension.
